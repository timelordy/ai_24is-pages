Лабораторная 1. Измеряем качество ответа LLM

Результат за 90 минут

Вы создадите небольшой benchmark: восемь заметок, два контролируемых прогона и численная оценка ответов. Цель — доказать данными, помогли ли контекст, формат и ограничения.

00–15. Подготовьте эталон

  1. Откройте benchmark.json, но сначала смотрите только поля case и text.
  2. Для каждого кейса вручную заполните ожидаемые title, status, due в своей таблице.
  3. Только после этого сравните разметку с gold. Спорныетесь не о словах, а о правиле: точной даты нет — due=null.

Контрольная точка: 8 размеченных кейсов и список неоднозначностей.

15–35. Выполните два прогона

Используйте одну и ту же модель.

  • Baseline: Выдели задачу, статус и срок из заметки.
  • Improved: потребуйте JSON с case, title, status, due; запретите догадки; дайте один пример с due=null.

Отправляйте все восемь заметок. Не исправляйте ответы руками. Сохраните массивы в runs/baseline.json и runs/improved.json.

Контрольная точка: 16 сырых результатов и точные тексты двух запросов.

35–65. Посчитайте ошибки

Выполните:

python score_benchmark.py runs/baseline.json
python score_benchmark.py runs/improved.json

Для каждого прогона выпишите: валидность формата, точность полей, число выдуманных значений. Вручную разберите минимум две ошибки improved-версии или два самых рискованных места, если ошибок нет.

Контрольная точка: две сводки метрик и таблица ошибок по кейсам.

65–90. Сделайте вывод и защитите

Исправьте done_ids в diagnosis.py. Сформулируйте один вывод, подтверждённый числами, и одно ограничение опыта. На защите преподаватель даст девятую заметку: сначала предскажите риск, потом выполните запрос и проверьте ответ.

Работа не принимается по одному удачному скриншоту или если одновременно менялись модель, данные и запрос.
