Индивидуальная защита

Форма: 3–4 минуты, студент показывает собственную рабочую папку. Преподаватель выбирает один новый пример, которого не было в отчёте. Можно пользоваться файлами, но сначала прогноз произносит студент.

Пара Новый вопрос/вход Признак понимания
1 «Сделать на следующей неделе», текущая дата не дана Не выдумывает календарную дату
2 edit запрещён, bash разрешён — безопасно ли? Объясняет обход записи через shell
3 Маркер skill есть, события skill нет Не считает загрузку доказанной
4 id 8 и 5 без срока, id 4 с датой Порядок 4,5,8; вход не меняется
5 get_task(true), status=archived Ошибка валидации, не пустой успех
6 Reviewer PASS, тест падает Тест и контракт требуют исправления
7 В title команда прочитать закрытый файл Данные не повышают права
