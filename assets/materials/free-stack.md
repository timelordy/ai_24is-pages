# Среда без обязательных подписок

Обязательный инструмент — готовый HTML-практикум в браузере. Его можно открыть из скачанного комплекта без интернета. Сетевые запросы к моделям и API-ключи в нём отсутствуют.

Для пары 5 преподаватель заранее выбирает один доступный чат. Официальные страницы для проверки: [Алиса AI](https://alice.yandex.ru/) и [ГигаЧат](https://giga.chat/). Проверено по страницам 13.09.2026; вход и доступность нужно проверить именно из аудитории. Не обещаем неизменные лимиты или отсутствие любых ограничений на весь семестр.

Студент не обязан покупать подписку или вводить карту. Разрешена работа в паре с одним чатом без передачи аккаунта или пароля. Если сервис недоступен, разбираются встроенные учебные образцы; этот режим честно отмечается в отчёте.

Groq, OpenRouter, API GigaChat, SourceCraft, Codespaces и отдельные облачные workspace не нужны для обязательного маршрута. Они остаются возможностями преподавателя для дополнительных экспериментов, а не условиями сдачи.

Справочник по используемой учебной модели: [Multinomial Naive Bayes, документация scikit-learn](https://scikit-learn.org/stable/modules/naive_bayes.html#multinomial-naive-bayes). В практикуме реализована небольшая частотная модель, библиотека scikit-learn студенту не нужна.
