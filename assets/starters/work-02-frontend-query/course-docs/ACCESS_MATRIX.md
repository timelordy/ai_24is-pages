# Программы для занятия и варианты на случай сбоя

| Инструмент | Для чего нужен | Если не работает |
|---|---|---|
| VS Code | Открывать и менять файлы проекта. | Работай на подготовленном учебном компьютере. |
| Git | Хранить историю изменений проекта на компьютере. | Проверь установку по первой работе. Историю проекта не удаляй. |
| Node.js 22+ | Запускать учебный сайт и тесты. | Проверь версию и установку по первой работе. |
| OpenCode V1, пакет `opencode-ai` | Агент с ИИ, который работает в терминале. | Покажи ошибку преподавателю. Не устанавливай вторую версию рядом. |
| Inception Mercury 3 | Основной сервис и модель для ответов OpenCode. | Используй свой ключ. Если доступ закрыт, выбери согласованный запасной вариант. |
| Freebuff CLI | Альтернативный агент для того же проекта. Использует собственный сервис моделей. | Следуй отдельной инструкции. Если вход или доступ недоступен, выбери другой вариант с преподавателем без снижения оценки. |
| OpenCode Free | Первый запасной вариант для OpenCode. | Выбери доступную бесплатную модель через `/models` и проверь, что агент читает проект. |
| NVIDIA | Второй запасной сервис для OpenCode. | После согласования с преподавателем подключи свой ключ через `/connect`. |
| GitVerse | Хранить отправленную копию проекта для преподавателя. | Сохрани файлы и описание работы на компьютере до восстановления доступа. |
| GitVerse CI | Проверять отправленный код на GitVerse. | Запусти `npm test` на компьютере и укажи, что проверка CI не прошла или не запускалась. |
| Готовый пример без ИИ | Продолжить занятие, если сервисы недоступны. | Сравни версии кода, объясни ожидаемый результат и запусти тесты. |

## Аккаунты и доступ

Пользуйся личным аккаунтом и личным ключом, если выбранный сервис его требует. Общий ключ группы и платная подписка не нужны для обязательной оценки. Бесплатный доступ может иметь ограничения, поэтому перед занятием проверь условия.

Freebuff не настраивается как провайдер OpenCode. В обычном маршруте Freebuff не нужен ключ Inception. Регистрация, вход и проверка личности могут потребоваться; доступные модели, лимиты и доступность сервиса могут меняться. Если не можешь пройти проверку или не хочешь её проходить, выбери другой вариант с преподавателем без снижения оценки.

При смене сервиса файлы проекта и задание остаются. Новому помощнику кратко объясни цель, текущие изменения и последнюю ошибку. Проверь по файлу или экрану, что он действительно видит проект.

Порядок настройки OpenCode и Freebuff описан в `STUDENT_SETUP.md` этой папки. В отчёте укажи, что выполнил и что не смог проверить из-за доступа или сети.
