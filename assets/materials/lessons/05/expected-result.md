# Ожидаемый результат пары 5

Рабочий локальный MCP-конфиг, журнал двух tool calls и двух ошибок, неизменные данные.

- tools/list объявляет только list_tasks и get_task.
- list_tasks(todo) возвращает id 1,2,4; get_task(2) сохраняет null.
- Неизвестный id, неверный статус и недоступные данные дают ошибку.
- Хеш tasks.json не меняется; сетевой аккаунт для MCP не нужен.

Формулировки ответа модели могут отличаться. Проверяются факты и воспроизводимость, а не совпадение текста с образцом.
