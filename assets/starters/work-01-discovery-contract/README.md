# 1. Первый разговор с агентом в своём проекте

**Цель:** Запустим готовый сайт, попросим ИИ разобраться в его файлах и проверим ответы на экране.

**Пример рабочей ветки в инструкции:** `stage/01-discovery`. Имя ветки не является критерием отчёта.

На сайте курса есть иллюстрации, снимки программ и схемы с переключением. Здесь те же действия текстом. Для вводной встречи достаточно частей 1–10; полная работа включает знакомство с агентом, самостоятельную проверку результата и короткую свободную заметку.

## Часть 3. Установи VS Code

**Где работаем:** В браузере и VS Code

В VS Code будем открывать файлы сайта и писать поручения помощнику. Сейчас установим программу и найдём панель для команд.

**Два окна для разных действий:** VS Code нужен, чтобы читать и менять файлы сайта. Браузер покажет результат: страницу с заявками. Установив VS Code, откроем в нём терминал, панель для ввода команд.

### 1. Скачай редактор

Открой [страницу VS Code](https://code.visualstudio.com/Download), выбери Windows и User Installer x64. Установи и запусти программу.

**Проверь у себя:** Открылось окно Visual Studio Code.

### 2. Найди место для команд

В верхнем меню выбери «Терминал → Создать терминал» (Terminal → New Terminal). Внизу откроется панель со строкой текста и мигающим курсором. Щёлкни рядом с курсором: сюда будем вводить команды.

**Проверь у себя:** Внизу VS Code открыта панель терминала и виден курсор.

**Подсказка:** PS, путь к папке и знак > уже написаны программой. Копировать их не нужно. Вводи только команду из инструкции.

### 3. Проверь Git в терминале

Введи git --version в нижней панели и нажми Enter. Программа напечатает свой номер версии под командой.

**Введи в терминал VS Code:**

```text
git --version
```

**Пример ответа после `git --version` — вводить не нужно:**

```text

```

**Проверь у себя:** Под введённой командой появилась строка git version и номер. Номер может отличаться от снимка.

**Подсказка:** Текст под командой показывает её результат. Его повторно вводить не нужно. Если Git не найден, закрой VS Code, открой снова и повтори только эту проверку.

**Результат шага:** VS Code открыт, ты знаешь, где его терминал.

## Часть 4. Установи Node.js

**Где работаем:** В браузере и терминале VS Code

Файлы сайта уже написаны, но их ещё нужно запустить. Для этого установим Node.js. Это программа, которая выполняет код JavaScript на компьютере. Такую программу называют средой выполнения.

**Что будет после установки:** Появится команда node: с её помощью помощник запустит server.mjs. Эта программа передаст страницу с заявками в браузер. Вместе с Node.js установится npm, через него на следующем шаге установим OpenCode.

### 1. Выбери установщик для Windows

Открой [страницу Node.js](https://nodejs.org/en/download). Выбери выпуск с пометкой LTS, версию 22 или новее. Прокрути до блока готового установщика: Windows, x64, Windows Installer (.msi). Скачай файл и установи программу. Затем закрой и снова открой VS Code.

**Проверь у себя:** Установка завершена, VS Code открыт заново.

**Подсказка:** На снимке показан именно блок для Windows. Команды Docker в верхней части страницы пропусти.

### 2. Проверь Node.js и npm

Открой «Терминал → Создать терминал». Введи первую команду ниже и нажми Enter. После появления ответа введи вторую и снова нажми Enter.

**Введи в терминал VS Code:**

```text
node --version
npm.cmd --version
```

**Пример ответа после `node --version` — вводить не нужно:**

```text
v24.15.0
```

**Пример ответа после `npm.cmd --version` — вводить не нужно:**

```text
11.12.1
```

**Проверь у себя:** После node --version появился номер с буквой v, после npm.cmd --version ещё один номер. Если вместо номера показана ошибка, установку пока нельзя считать проверенной.

**Результат шага:** Компьютер готов запускать учебный сайт.

## Часть 5. Установи помощника OpenCode

**Где работаем:** В терминале VS Code

Мы уже пробовали GigaChat, но с подключением возникли сложности. Теперь установим OpenCode: в нём будем поручать ИИ прочитать файлы, запустить сайт и записать отчёт. Модель подключим на шаге 8.

**Как будем работать с помощником:** Ты пишешь поручение в OpenCode. Помощник может прочитать файлы или предложить команду. Перед выполнением предложенного действия ты читаешь его, а затем проверяешь результат. Такого помощника называют агентом.

### 1. Установи OpenCode и проверь результат

В терминале VS Code введи первую команду и нажми Enter. Дождись завершения установки. Затем введи вторую команду: она покажет версию OpenCode.

**Введи в терминал VS Code:**

```text
npm.cmd install -g opencode-ai
opencode.cmd --version
```

**Пример ответа после `opencode.cmd --version` — вводить не нужно:**

```text
1.19.3
```

**Проверь у себя:** После второй команды появился номер версии OpenCode. Это подтверждает установку; подключение ИИ проверим позже.

**Подсказка:** Если компьютер пишет, что команда не найдена, закрой и снова открой VS Code, затем повтори проверку. Саму установку без причины повторять не нужно.

**Результат шага:** OpenCode установлен. Сам разговор с ИИ начнём после открытия папки проекта.

## Часть 8. Подключи ИИ к OpenCode

**Где работаем:** В браузере и внутри OpenCode

Подготовим четыре файла для OpenCode. Затем войдём в Inception через Google, получим ключ и подключим модель.

**Почему нужны ещё четыре файла:** В скачанном проекте остались инструкции для прежнего помощника. Набор обновит README.md и TASK.md, добавит opencode.json и предложит необязательный шаблон REPORT.md. Свои заметки заменять не нужно. Файлы самого сайта и папка .git останутся на месте.

**Google и ключ — для разных действий:** Через Google входим в кабинет Inception. В кабинете получаем ключ API, который даст OpenCode доступ к ИИ. Пароль Google в OpenCode вводить не нужно.

### 1. Добавь актуальные файлы для этой работы

Этот набор нужен при первой подготовке. Скачай его и добавь opencode.json, README.md и TASK.md в Campus-ServiceDesk рядом с package.json. REPORT.md из набора — необязательный шаблон: скопируй его, если ещё не начинал свои заметки. Если уже записывал выводы, сохрани свой файл и не заменяй его. Остальные файлы и папку .git не удаляй.

Скачай набор opencode-setup.zip на сайте курса.

**Проверь у себя:** В корне Campus-ServiceDesk есть opencode.json и актуальная инструкция TASK.md. Если у тебя уже были заметки, они сохранились.

### 2. Войди в Inception через Google

Открой Inception и нажми Continue with Google. Выбери свой аккаунт Google. Если вход в Google ещё не выполнен, войди обычным способом. Прочитай показанные условия и запрос доступа, затем продолжи, если согласен. После этого вернёшься в кабинет Inception. Если кабинет уже открыт, переходи к получению ключа.

[Открыть Inception](https://platform.inceptionlabs.ai/)

**Проверь у себя:** Открыт твой кабинет Inception. Ты вошёл через Google; отдельный пароль Inception создавать не понадобилось.

**Подсказка:** Если кабинет не даёт создать ключ или требует оплату, открой помощь по подключению и выбери запасной вариант с преподавателем. Не нужно оплачивать сервис только ради продолжения этого шага.

## Часть 9. Разберись с версиями и создай ветку

**Где работаем:** В поле сообщения OpenCode

Сначала сохраним подготовленные настройки. Потом агент заполнит REPORT.md в твоей рабочей ветке. Сможем сравнить пустой отчёт и заполненный, не создавая ещё одну папку.

**Два имени одной папки:** main — исходный сайт с шаблоном отчёта. stage/01-discovery — твой вариант для первой работы. Агент выберет нужное имя в Git; создавать вторую папку не надо.

**Коммит на этой работе:** Попросим агента сохранить подготовку с подписью «Подготовка к работе с OpenCode». Эта запись в истории — коммит. На шаге 13 отдельно сохраним заполненный отчёт.

### 1. Посмотри, что уже хранится в Git

В OpenCode нажимай Tab, пока возле поля сообщения не появится Plan. Вставь запрос ниже и нажми Enter. Попросим помощника посмотреть папку и записи Git, ничего не меняя.

**Отправь агенту в OpenCode:**

```text
Не меняй файлы и историю Git.
Проверь, какая папка открыта и откуда получен репозиторий. Покажи текущую ветку и последний коммит.
Объясни простыми словами, что уже сохранено в main и какие файлы появились или изменились после добавления набора для OpenCode.
Если истории Git нет, скажи об этом: я мог скачать ZIP.
```

**Проверь у себя:** В ответе есть имя main, последняя запись Git и отдельный список изменённых или добавленных файлов для OpenCode. Если ты скачал ZIP, агент сообщил, что истории Git нет.

**Отправь агенту в OpenCode:**

