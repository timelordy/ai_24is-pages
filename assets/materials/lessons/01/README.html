Пара 1. Запрос, контекст и проверка ответа

90 минут · один учебный Python-проект · бесплатная обязательная часть.

Что изучаем

Разделять постановку задачи и ответ модели; проверять извлечение данных; читать простую Python-функцию.

Что делаем

Два запроса, два сырых ответа с названием модели и датой, таблица фактов/ошибок и исправленная диагностика Python.

Подготовка и независимый старт

Из корня полного комплекта: python scripts/start_lesson.py 01 ../my-lesson-01. Перейдите в созданную папку. Либо скачайте отдельный starter с портала и распакуйте его. Не копируйте конфиги поверх своей прошлой работы. Исходные файлы · Материалы.

Объяснение

LLM продолжает текст по контексту и может дать правдоподобный неверный ответ. Контекст — предоставленные данные, а не знание всех файлов компьютера. Пример задаёт формат, ограничения задают границы. Сравниваем ответы на одном наборе: смена и модели, и запроса одновременно не объяснит причину разницы.

Шаги

  1. Откройте notes.txt. Вручную выпишите явно указанные сроки и неизвестные значения.
  2. В доступном чате отправьте короткий запрос «Выдели задачи из заметок». Сохраните точный текст запроса и сырой ответ.
  3. Повторите на тех же данных с форматом: массив title/status/due; due=null, если срока нет; ничего не додумывать. Добавьте один пример.
  4. Сравните с другой доступной моделью. Если доступна одна, обменяйтесь обезличенным ответом с соседом или используйте materials/sample-response.json, пометив его как учебный пример.
  5. Найдите ошибку в образце ответа. Проверьте все три срока по исходным заметкам; сохраните таблицу сравнения.
  6. Запустите python diagnosis.py. Вручную исправьте TODO, объясните ожидаемый список [3] и повторите запуск.

Что должно получиться

Два запроса, два сырых ответа с названием модели и датой, таблица фактов/ошибок и исправленная диагностика Python.

Проверка и критерии сдачи

  • В ответе три задачи; у «Прочитать требования» срок 2026-09-20.
  • У «Проверить отчёт» due=null: слово «потом» не дата.
  • Срок установки Python 2026-09-14, status=done.
  • diagnosis.py завершается с кодом 0; студент объясняет фильтр status.

Что показать преподавателю

Покажите одну ошибку ответа и строку исходника, которая её опровергает. Что изменилось после добавления контекста? Почему валидный JSON ещё не означает правильные данные? Сдайте отчёт, исходные доказательства и свою рабочую папку. Самоотметка на сайте не является оценкой.

Для сильных

Составьте 5 новых заметок с неоднозначностями. Посчитайте долю правильно извлечённых полей на одинаковом наборе, не составляя общий рейтинг брендов.

Если модель недоступна, используйте резервный маршрут. Непроведённые живые проверки отмечайте NOT_RUN.
