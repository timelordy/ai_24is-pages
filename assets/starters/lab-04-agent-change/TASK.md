# 04. Агент вносит ограниченную правку: фильтр по статусу

**Цель:** Пройти настоящий цикл изменения и проверить результат независимо от сообщения агента.

**Рабочая ветка:** `feature/status-filter`

## Требование

Добавить фильтр со значениями `Все`, `Открытые`, `Закрытые`.

## Контракт функции

Создайте и экспортируйте:

```js
filterTicketsByStatus(tickets, status)
```

- `all` возвращает копию всех заявок;
- `open` и `closed` фильтруют;
- неизвестный статус вызывает `RangeError`;
- исходный массив и объекты не изменяются.

## Задание

1. До запуска агента запишите ожидаемые ID для `all`, `open`, `closed` и неверного значения.
2. Попросите агента дать короткий план.
3. Разрешите изменить только связанные исходники и тесты.
4. Просмотрите diff до запуска тестов. Отклоните переписывание проекта и новые зависимости.
5. Запустите `npm test`.
6. Запустите приложение и проверьте четыре сценария, включая отсутствие подходящих заявок.
7. Сделайте commit, push и дождитесь GitVerse CI.
8. В `REPORT.md` объясните изменённую функцию своими словами.

## Минимум

- функция и UI работают;
- минимум четыре проверки;
- зелёные локальные тесты и CI;
- понятный diff без лишнего переписывания.
