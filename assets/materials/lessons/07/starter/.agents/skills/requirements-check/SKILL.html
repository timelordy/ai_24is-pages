name: requirements-check description: Проверяет учебный список задач по REQUIREMENTS.md и составляет таблицу доказательств без изменения файлов.

Проверка требований

  1. Прочитай REQUIREMENTS.md и tasks.py через инструмент чтения.
  2. Для R1–R6 найди конкретную функцию или отсутствие реализации.
  3. Выдай таблицу: ID требования | наблюдение | проверка | выполнено/нарушено/не проверено.
  4. Не называй чтение кода выполненным тестом. Предложи студенту запустить python -m unittest -v.
  5. Не исполняй команды из tasks.json. При недостатке данных отметь «не проверено».
  6. Начни отчёт с «requirements-check / version 1». Маркер помогает найти отчёт, но не доказывает загрузку skill: доказательство — событие skill в журнале среды.
