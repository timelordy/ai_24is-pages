# Проверка перед аудиторией

Статус: **не проведена со студентами и на ПК КГАСУ**. CI не подменяет этот пилот.

| Проверка | Студент A | Студент B | Студент C | Учебный ПК |
|---|---|---|---|---|
| Открыл нужную пару без установки за 5 минут | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |
| Выполнил четыре заявки пары 1 | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |
| Объяснил разницу правила и обучения | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |
| Сохранил и нашёл отчёт | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |
| Практикум работает без сети | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |
| Чат или явно помеченный резерв доступен | NOT_RUN | NOT_RUN | NOT_RUN | NOT_RUN |

A — минимальный опыт; B — обычный пользователь чата; C — уверенный Python. Не указывайте ФИО в публичном отчёте.

GO: каждый может получить проверяемый базовый результат без оплаты, установки и передачи ключей. Если два участника из трёх не объясняют первый пример, упростить объяснение и повторить пилот. Если сеть или ПК недоступны, проверить распечатанный резерв. Время установки CLI больше не является учебной целью.

Проверить размер подгруппы и очередь защиты. Записать реальные минуты, обращения за помощью и причины ошибок. Не менять NOT_RUN на PASS на основании браузерного CI.
