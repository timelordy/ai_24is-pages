# Что нужно для занятия и чем это заменить

| Что используем | Зачем | Что делать при проблеме |
|---|---|---|
| VS Code | открывать и менять файлы | работать на подготовленном учебном компьютере |
| Git | сохранять версии проекта | проверить установку по первой работе; не удалять историю проекта |
| Node.js 22+ | запускать учебный сайт и тесты | проверить версию и установку по первой работе |
| OpenCode V1, пакет opencode-ai | помощник с ИИ в терминале | показать ошибку преподавателю; не устанавливать рядом другую версию |
| Inception Mercury 3 | основной сервис ответов ИИ | использовать свой ключ; при отказе выбрать запасной сервис |
| OpenCode Free | первый запасной вариант ИИ | выбрать доступную бесплатную модель через /models и проверить чтение файла |
| NVIDIA | второй запасной вариант ИИ | подключить свой ключ через /connect после проверки преподавателем |
| GitVerse | отправлять работу преподавателю | сохранить файлы и описание задачи на компьютере до восстановления доступа |
| Автоматические проверки GitVerse, или CI | проверять отправленный код | выполнить npm test на компьютере; отметить, что проверка на сайте ещё не состоялась |
| Готовый пример изменений без ИИ | продолжить занятие при отказе всех сервисов | сравнить старый и новый код, предсказать результат и запустить тесты |

Каждый использует личные аккаунты и ключи. Для обязательных баллов не требуются общий ключ группы и платная подписка. Бесплатные предложения имеют ограничения; проверяйте условия до занятия.

При смене сервиса ИИ файлы проекта и задание сохраняются. Объясните новому помощнику цель, покажите текущие изменения и последнюю ошибку. Не считайте обычный ответ в чате доказательством того, что помощник умеет читать файлы.

Подключение описано в STUDENT_SETUP.md этой папки. В отчёте честно укажите, что удалось выполнить, а что осталось непроверенным из-за доступа или сети.
