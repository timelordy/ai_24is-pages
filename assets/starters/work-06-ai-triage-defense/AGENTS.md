# Campus ServiceDesk · правила для AI-агента

## Перед изменением
- Прочитай `TASK.md`, `docs/REQUIREMENTS.md` и связанные тесты.
- Сначала дай короткий план и назови затрагиваемые файлы.
- Не расширяй задачу без явного требования.

## Границы
- Не добавляй внешние dependencies без согласования.
- Не переписывай проект на framework.
- Не меняй тесты только ради зелёного результата.
- Не удаляй существующие проверки контрактов.
- `.env`, токены и реальные пользовательские данные не должны попадать в репозиторий.

## После изменения
- Покажи `git diff --stat` и существенные изменения.
- Запусти `npm test` и приведи реальный итог.
- Перечисли ручные сценарии, которые проверены.
- Отдельно укажи, что осталось непроверенным.
