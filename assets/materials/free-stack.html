Бесплатный стек · проверка источников 13.09.2026

«Бесплатно» здесь означает отсутствие обязательного платежа. Доступность конкретной модели, квота, регион и нагрузка могут измениться даже между занятиями. Проверка документации не подтверждает доступ с сети КГАСУ; его проверяет пилот.

Вариант Роль Ограничение
Python + учебный проект Обязательная локальная основа Python 3.11+, без pip-зависимостей проекта
OpenCode + бесплатная модель Zen Основная агентная среда Выбрать явно бесплатную модель; наличие в каталоге не гарантирует доступ и устойчивый tool calling
Доступный ChatGPT/Claude/DeepSeek/Gemini в чате Пара 1 и резерв анализа Доступ к чату не равен доступу к API или агентным инструментам
Gemini CLI, вход Google Резервная агентная среда Условия аккаунта/региона, квоты; конфиги OpenCode автоматически не переносятся
Ollama + локальная модель Опция на подготовленном ПК Требования к RAM, загрузка весов, качество tool calling; не обязательна для ноутбука студента

Основной маршрут

  1. Установите Python и проверьте python --version. На Windows при необходимости используйте py -3.11, но во всех командах последовательно указывайте один интерпретатор.
  2. Установите Git. Для учебного снимка: git init, git add ., git commit -m "lesson start". Если Git требует автора, задайте git config user.name "Student" и git config user.email "student@example.invalid" только внутри учебного репозитория.
  3. Выберите способ установки из официальной инструкции OpenCode. Через установленный Node.js/npm: npm install -g opencode-ai@1.18.30. Это версия, выбранная для воспроизводимой проверки курса. После установки: opencode --version. Глобальная установка нужна только на личном ПК; на учебном ПК преподаватель подготавливает её заранее. Не обходите запреты администратора.
  4. В папке starter выполните opencode. Откройте /models и выберите доступную модель с пометкой Free. Не включайте автоматическое пополнение и не добавляйте платёжные данные для задания.
  5. Проверьте один настоящий read и запрет edit. Затем, на паре 5, opencode mcp list и вызов tasks_list_tasks.

На дату проверки таблица Zen содержит бесплатные позиции, включая Big Pickle и MiMo-V2.5 Free. Состав временный. Некоторые бесплатные предложения допускают использование переданных данных для улучшения модели: в курсе только вымышленные данные. Модель не зафиксирована в конфиге намеренно; перед парой преподаватель выбирает и проверяет доступный вариант. Подписки чат-сервисов не предполагаются переносимыми в OpenCode.

Резерв

Gemini CLI: устанавливается отдельно, например npm install -g @google/gemini-cli, запуск gemini. Вход через Google и доступность бесплатного уровня зависят от аккаунта и региона. Официальная страница квот на дату проверки указывает до 1000 запросов модели в день для Google account / Code Assist Individual; действуют и ограничения частоты. Не путайте это с гарантированными 1000 выполненными заданиями. Преподаватель проверяет доступ до занятия, без включения оплаты.

Файлы opencode.json и reviewer.md не являются конфигом Gemini CLI. В резерве используйте ручное чтение контекста и отдельную сессию проверки, зафиксируйте различия; живую проверку OpenCode проведите на учебном ПК. Не выдавайте такой резерв за идентичный runtime.

Ollama ↔ OpenCode: опциональная интеграция для заранее подготовленного ПК. Преподаватель проверяет модель с инструментами на реальном железе и измеряет задержку. Не заставляйте всю группу скачивать многогигабайтные веса за 15 минут. Локальная модель также должна пройти pilot-checklist; словесный ответ не заменяет tool call.

Если ни один агентный маршрут недоступен: продолжайте анализ в доступном чате, запускайте локальные тесты и probe_mcp.py. Для живых вызовов назначается работа на подготовленном ПК/другая дата. Полностью автономный офлайн-агент на любом слабом ПК не обещается.

Официальные технические источники

  • Permissions: allow/ask/deny, последнее совпавшее правило, отдельные права bash/edit.
  • Agent Skills в OpenCode и формат Agent Skills.
  • Агенты и steps: лимит итераций не равен общему лимиту времени/всех дочерних вызовов.
  • Локальный MCP-конфиг и официальное руководство MCP.

Сервер курса реализует небольшой совместимый stdio-поднабор MCP 2024-11-05. Это учебный код, не замена полного SDK для промышленного сервера. CI проверяет совместимость официальным Python SDK; студенты SDK устанавливать не обязаны.
