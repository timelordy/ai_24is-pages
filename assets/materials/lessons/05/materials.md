# Материалы пары 5

Рабочие файлы: [START](starter/START.md), [требования](starter/REQUIREMENTS.md), [код](starter/tasks.py), [данные](starter/tasks.json), [тесты](starter/test_tasks.py).

MCP стандартизирует обмен между средой и инструментом. Модель выбирает имя и аргументы, сервер валидирует их и возвращает данные. В обязательной части сервер запускается локально через stdio, ничего не слушает в сети и не пишет задачи. Метка readOnlyHint описательная: отсутствие write-кода и проверка данных важнее метки.

Разбор преподавателя: Покажите последовательность initialize → tools/list → tools/call. Запустите python probe_mcp.py: это настоящий обмен с процессом сервера, но ещё не доказательство выбора инструмента моделью. Затем покажите tasks_list_tasks в OpenCode и отличите эти две проверки.

Термины используйте буквально: модель генерирует ответ; среда выполняет инструмент; тест сравнивает наблюдение с контрактом. В отчёте отделяйте эти три источника доказательств.
