# Требования к ServiceDesk Lite

Приложение показывает синтетические заявки небольшой сервисной службы. Пользователь должен видеть заголовок, описание, статус и приоритет каждой заявки.

Курс постепенно добавляет фильтр, поиск и сортировку. Каждое изменение должно быть небольшим, проверяемым и не требовать внешних библиотек.

## Ограничения

- Node.js 20+;
- без runtime-зависимостей;
- данные остаются в `src/data.js`;
- нельзя переписывать проект на фреймворк;
- пользовательский ввод выводится через `textContent`, а не исполняется как HTML;
- тесты не изменяются ради маскировки ошибки в коде.
