# С чего начать

На сайте курса откройте первую работу и идите по карточкам. На каждом шаге видно, где действовать, что попросить у агента и какой результат проверить. Опыт с Git и терминалом не требуется.

Курс «Методы искусственного интеллекта» учит работать с агентом на одном учебном сайте Campus ServiceDesk. Вы ставите задачу, уточняете план, смотрите результат, возвращаете ошибку на исправление и объясняете одно решение. Готовое сообщение ИИ само по себе работу не завершает.

## Первое занятие

1. По карточкам установите Git, VS Code, Node.js и OpenCode V1. Git сохраняет историю версий, VS Code открывает файлы, Node.js запускает сайт, OpenCode выполняет задачи с помощью модели ИИ.
2. Скачайте проект и откройте в VS Code папку с `package.json`. В меню «Терминал → Создать терминал» выполните `npm start` и откройте показанный адрес. В браузере должны появиться 12 заявок. Оставьте терминал работающим; остановка выполняется через `Ctrl+C`.
3. Подключите OpenCode по карточке занятия. Поставьте свой вопрос о сайте и самостоятельно проверьте ответ по файлам или в браузере. Уточняйте его, если это помогает вашей задаче. Код приложения на первой работе сохраняем без изменений.
4. Коротко опишите свою работу с агентом и проверенный результат. Можно написать самому или с помощником, в удобной форме и объёме. REPORT.md — необязательная заготовка; сохранение заметки в Git показано как один из способов.

`TASK.md` можно скачать как памятку или передать агенту. В `REPORT.md` есть необязательные подсказки для заметки. Читать эти файлы целиком до первого действия не нужно: маршрут есть на странице.

Если `package.json` не найден, проверьте открытую папку. Если заблокирован `npm.ps1`, выберите в меню терминала «Command Prompt / Командная строка» или используйте `npm.cmd start`. При ошибке сохраните её текст и попросите агента объяснить причину до правки.

## Со второго занятия

Продолжайте свой проект. Перед новой работой сохраните прежнюю заметку и обновите документы текущего занятия. В карточках показан вариант с веткой `stage/01-discovery`. Если первая заметка сохранена иначе, перенесите её из фактического места хранения вместе с преподавателем; переделывать её под шаблон не нужно. На работе 02 файл проверки и два шаблона переносятся из архива восстановления, временно распакованного вне проекта.

Опишите, что человек должен сделать на сайте и увидеть. Дайте агенту границы, обсудите план и разрешите согласованную правку. В VS Code откройте «Управление версиями» и сравните старые и новые строки. Это сравнение называется diff. Затем сами выполните сценарий в браузере. Автоматические тесты может запускать агент: при ошибке попросите объяснение и откройте указанное место. Количество успешных тестов не является целью занятия.

После обратной связи исправьте подтверждённую ошибку и повторите сценарий. Сохраните выбранные файлы в коммите, отправьте ветку в свою копию на GitVerse и создайте запрос на слияние, Merge Request. Он показывает преподавателю изменения до добавления в основную ветку `main`. Дождитесь автоматической проверки последней версии, разберите замечания и после принятия объедините результат с `main`.

## Если помощник не отвечает

Внутри OpenCode введите `/models` и выберите доступный OpenCode Free. NVIDIA подключайте через `/connect` личным ключом после проверки с преподавателем. При смене модели сообщите задачу, рабочую ветку, изменённые файлы и последнюю ошибку. Сначала попросите прочитать текущее состояние.

При полном отсутствии связи разберите обезличенный ответ преподавателя и проверьте его локально. Укажите источник и невыполненные действия в отчёте. Этот разбор не выдавайте за свою сессию. Ключи не вставляйте в чат, отчёт или файлы проекта.

## Что покажете преподавателю

На первой работе покажите свою работу с агентом, результат самостоятельной проверки и короткую заметку. Запросы, ход работы и решения могут различаться; обязательных трёх фактов, уточнения, найденной ошибки, версий программ или конкретного формата отчёта нет. На следующих работах применяются критерии их TASK: сценарий на сайте, работа с агентом, проверка изменений и объяснение решения.
