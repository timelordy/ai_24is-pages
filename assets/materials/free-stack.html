На каких бесплатных моделях проводить курс

Проверено по официальным источникам 13.09.2026.

Короткий ответ

Гарантировать бесплатную облачную модель на весь семестр нельзя. OpenCode распространяется бесплатно, но модель работает у отдельного провайдера. Провайдер может изменить список моделей, квоту, правила регистрации или доступность в регионе.

Для пар 2–7 используйте такую очередь:

  1. Groq + qwen/qwen3.6-27b — основной кандидат. У Groq есть Free Plan, OpenCode подключает Groq напрямую, модель поддерживает локальные tools. Текущий лимит: 30 запросов в минуту, 1000 в день и 200 тысяч токенов в день.
  2. Groq + openai/gpt-oss-20b — запасная модель на том же endpoint с теми же опубликованными дневными лимитами.
  3. OpenRouter + nvidia/nemotron-3.5-lightning:free — второй провайдер, если Groq недоступен. Бесплатный вариант поддерживает tools.
  4. OpenRouter + nvidia/nemotron-3-ultra-550b-a55b:free — следующий запасной кандидат.
  5. OpenRouter + openrouter/free — аварийный роутер. Он сам выбирает доступную бесплатную модель с нужными возможностями. Модель между запусками может отличаться, поэтому его нельзя использовать для честного сравнения моделей на паре 6.
  6. NVIDIA + nemotron-3-super-120b-a12b — прямой бесплатный trial endpoint для обучения и прототипирования. Возможны индивидуальная проверка аккаунта и меняющийся rate limit.
  7. Ollama + qwen3:8b — локальный резерв на заранее проверенном ПК. Размер загрузки около 5,2 ГБ; модель заявляет поддержку tools.
  8. Ollama + qwen2.5-coder:7b — второй локальный кандидат, около 4,7 ГБ.

Для одной лабораторной фиксируйте одну конкретную модель. Не переключайте модель посередине опыта, кроме случая недоступности; переключение запишите в отчёт.

Что именно бесплатно, а что нет

Маршрут Нужен аккаунт Платёж Ограничение
Python + учебный проект нет нет Python 3.11+, без pip-зависимостей проекта
Groq Free Plan да, нужен API key карта нужна только при переходе на Developer Plan опубликованные лимиты зависят от модели; для рекомендуемых — 1000 запросов и 200 тысяч токенов в день
OpenRouter :free да, нужен API key бесплатная модель имеет цену 0 без купленных кредитов официальный лимит — 50 запросов в день суммарно; доступность меняется
NVIDIA API Catalog да, нужен API key trial endpoint бесплатен для разработки и обучения rate limit зависит от модели и нагрузки; у части аккаунтов требуется ручная проверка
OpenCode Zen Free да, нужен API key сами перечисленные Free-модели имеют цену 0, но официальная настройка требует billing details все текущие Free-позиции помечены как временные; это не обязательный маршрут курса
Ollama локально нет нет платы за запросы нужны место на диске, достаточная RAM и подготовка до пары; на CPU может быть медленно
Любой доступный чат зависит от сервиса для пары 1 достаточно бесплатного доступа чат не даёт OpenCode tools, permissions, skill и MCP

Один запрос студента может вызвать несколько обращений модели. Поэтому даже при лимите Groq 1000 запросов главным ограничением может стать дневной объём 200 тысяч токенов. Проект курса маленький, а агентные циклы ограничены. На паре 6 выполняйте один цикл executor → reviewer, на паре 7 запускайте только семь заданных сценариев.

Основной endpoint: Groq

Endpoint: https://api.groq.com/openai/v1. Ручная настройка URL не нужна: Groq уже есть в списке OpenCode.

  1. Создайте аккаунт в Groq Console и API key, оставаясь на Free Plan.
  2. В OpenCode выполните /connect, выберите Groq и вставьте ключ.
  3. В /models выберите qwen/qwen3.6-27b. Если модель недоступна, выберите openai/gpt-oss-20b.
  4. Попросите прочитать REQUIREMENTS.md и проверьте, что появился настоящий tool event.
  5. Сохраните заголовки/сообщение о rate limit, если получен 429; не повторяйте запрос бесконечно.

Groq пишет, что все размещённые модели поддерживают tool use. Его Free Plan на дату проверки публикует для обеих рекомендуемых моделей 30 RPM, 1000 RPD, 8 тысяч TPM и 200 тысяч TPD. Точные лимиты конкретного аккаунта показывает страница Limits.

Второй endpoint: OpenRouter

  1. Установите OpenCode по официальной инструкции. Проверенная курсом версия: opencode-ai@1.18.30.
  2. Создайте аккаунт OpenRouter и API key. Не покупайте кредиты для обязательной работы.
  3. В OpenCode выполните /connect, выберите OpenRouter и вставьте свой ключ.
  4. Выполните /models и найдите nvidia/nemotron-3.5-lightning:free.
  5. Если модели нет или она возвращает лимит, попробуйте nvidia/nemotron-3-ultra-550b-a55b:free, затем openrouter/free.
  6. До начала задания попросите агента прочитать REQUIREMENTS.md. В журнале должен быть настоящий вызов read. Текст «я прочитал» без события инструмента проверку не проходит.

OpenRouter официально указывает 50 бесплатных запросов в день для аккаунта без покупки минимум $10 кредитов. Поэтому он подходит как резерв, но слабее Groq для целой группы.

Третий endpoint: NVIDIA API Catalog

OpenCode прямо поддерживает NVIDIA: /connect → NVIDIA → API key с build.nvidia.com. Для курса сначала пробуйте nemotron-3-super-120b-a12b. Официальные страницы называют такие endpoints бесплатными для прототипирования, исследования, тестирования и обучения. Это trial-доступ: rate limit меняется, а у части новых аккаунтов встречается дополнительная проверка. Не делайте NVIDIA единственным маршрутом группы.

Текущий список бесплатных tool-моделей можно проверить перед парой:

python scripts/check_free_models.py

Скрипт ничего не регистрирует и не использует ключи: он читает публичные каталоги Zen и OpenRouter. Успешное появление модели в каталоге ещё не доказывает, что она отвечает из сети КГАСУ; это проверяет пилот.

OpenCode Zen: только дополнительный вариант

На дату проверки Zen показывает модели с нулевой ценой:

  • opencode/nemotron-3.5-lightning-free;
  • opencode/nemotron-3-ultra-free;
  • opencode/mimo-v2.5-free;
  • opencode/ling-3.0-flash-fin-free;
  • opencode/big-pickle;
  • opencode/muse-spark-1.3-contributor-free.

Однако официальная настройка Zen требует добавить billing details, а бесплатные позиции названы временными. Поэтому преподаватель может использовать уже проверенный Zen-аккаунт, но студент не обязан вводить карту. Big Pickle и часть других временных моделей также допускают сбор учебных запросов для улучшения сервиса; передаём только синтетические данные курса.

Локальный резерв: Ollama

Официальная интеграция OpenCode поддерживает Ollama по адресу http://localhost:11434/v1. На подготовленном ПК:

ollama run qwen3:8b
ollama launch opencode --model qwen3:8b

Если qwen3:8b плохо выполняет кодовые задания:

ollama run qwen2.5-coder:7b
ollama launch opencode --model qwen2.5-coder:7b

OpenCode рекомендует контекст порядка 16–32 тысяч токенов для tool calling. Не заставляйте всю группу скачивать модели во время пары. Сначала проверьте на учебном ПК реальные read, запрещённый edit, skill, MCP и reviewer. Локальный ответ без tool event не считается успешной проверкой.

Почему Gemini CLI больше не резерв этого курса

Gemini CLI — отдельная агентная среда, а не модель внутри OpenCode. В июне 2026 официальный проект объявил перенос бесплатного индивидуального доступа в Antigravity CLI. Поэтому старое обещание «1000 бесплатных запросов Gemini CLI в день» для этого курса больше не используется. Доступный Gemini в браузере остаётся подходящим для пары 1, но не заменяет OpenCode на парах с permissions, skill и MCP.

Условие запуска пар 2–7

За 1–3 дня до занятия преподаватель запускает pilot-checklist.md из аудитории. Формат можно проводить, если:

  • основной Groq-маршрут сделал настоящий read и хотя бы один tool call;
  • проверен лимит и студентам не предлагается оплата;
  • на случай массового rate limit подготовлен хотя бы один Ollama/кафедральный endpoint или перенос живой проверки без снижения балла.

Если ни один маршрут не прошёл пилот, инструментальную часть занятия переносим. Чат, запись экрана преподавателя и probe_mcp.py помогают разобрать материал, но не доказывают индивидуальную работу агента.

Официальные источники

  • Провайдеры OpenCode: Groq, NVIDIA, OpenRouter, Zen, Ollama и настройка ключей.
  • Groq Free Plan limits и tool use: актуальные квоты и поддерживаемые модели.
  • NVIDIA NIM for Developers: бесплатный trial-доступ для разработки и тестирования.
  • OpenCode Zen: актуальные идентификаторы, цена, временный статус и billing details.
  • OpenRouter Free Models: суффикс :free и меняющаяся доступность.
  • OpenRouter FAQ: 50 запросов/день без покупки $10 кредитов и openrouter/free.
  • Ollama Qwen3 и Qwen2.5-Coder: размеры, tools и запуск OpenCode.
  • Permissions OpenCode, Agent Skills, MCP.

Сервер курса реализует небольшой совместимый stdio-поднабор MCP 2024-11-05. CI проверяет его официальным Python SDK; студентам SDK устанавливать не обязательно.
