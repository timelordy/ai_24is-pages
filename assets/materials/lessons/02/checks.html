Проверочные сценарии

  • В read виден REQUIREMENTS.md, а не пересказ из пользовательского запроса.
  • check_integrity.py проходит: защищённый файл не изменён.
  • У edit и bash стоит deny; отсутствие попытки edit помечено как непроверенный runtime-запрет.

  • Отчёт содержит версию OpenCode, модель и способ запуска.

  • Начните с неизменённого starter, зафиксируйте исходный результат.

  • После работы запустите python -m unittest -v и python check_integrity.py.
  • Сверьте исходные доказательства с отчётом. Скриншот текста ответа не заменяет журнал инструмента.
  • Повторите один новый вход, выбранный преподавателем. PASS/FAIL/NOT_RUN указываются отдельно.
