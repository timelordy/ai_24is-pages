# 04. AGENTS.md и повторяемые правила работы

**Цель:** Сделать поведение агента предсказуемее и добавить поиск без раздувания задачи.

**Рабочая ветка:** `feature/ticket-search`

## Требование

Добавить поиск без учёта регистра по заголовку и описанию заявки.

## Задание

1. При наличии Sessions выполните `/init`; иначе создайте `AGENTS.md` из шаблона вручную.
2. Сократите файл до правил, специфичных для проекта: команды, границы, тесты и Git-процесс. Максимум 30 содержательных строк.
3. Попросите агента добавить и экспортировать `searchTickets(tickets, query)`.
4. Пустая строка должна возвращать копию всех заявок; поиск не меняет вход.
5. Добавьте поле поиска в UI и тесты для регистра, описания, пустого запроса и отсутствующего результата.
6. Проверьте, соблюдены ли правила `AGENTS.md`. Запишите одно подтверждённое соблюдение или нарушение с конкретным действием агента.
7. Запустите `npm test`, затем приложение, сделайте commit и push.

## Успешный результат

- `AGENTS.md` содержит не более **30 непустых содержательных строк** и явно включает: `npm test`, запрет новых dependencies, запрет менять тесты ради зелёного результата, требование показывать diff/проверки;
- `npm test` завершается с кодом `0`; после реализации проходят **15 тестов**: 5 базовых + 5 фильтра + 5 поиска;
- `searchTickets(tickets, "ПРОЕКТОР").map(x => x.id)` даёт `[1]`;
- поиск `"210"` по description даёт `[4]`;
- запрос из пробелов возвращает все **6** заявок новым массивом;
- `"марсианский"` возвращает `[]`;
- исходный массив не мутируется;
- UI-поиск без учёта регистра даёт те же результаты, а при отсутствии совпадений показывает **0 карточек** и понятное пустое состояние;
- в `REPORT.md` приведено одно конкретное правило `AGENTS.md` и доказательство, соблюдал или нарушил его агент.

## Не засчитывается, если

- `AGENTS.md` состоит из общих фраз вроде «пиши качественный код» и не содержит проверяемых ограничений;
- поиск работает только по title или зависит от регистра;
- пустой запрос возвращает исходный массив по той же ссылке;
- студент пишет «агент соблюдал правила», но не показывает конкретное действие/diff/команду;
- локальные тесты не проходят.

## Что сдавать

- `AGENTS.md`;
- commit с поиском;
- `REPORT.md` с выводом 15 тестов и разбором одного правила;
- четыре ручных проверки: `ПРОЕКТОР → 1`, `210 → 4`, пусто → 6, `марсианский → 0`.
