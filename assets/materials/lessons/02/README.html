Пара 2. Агент читает проект: инструкции и права

90 минут · один учебный Python-проект · бесплатная обязательная часть.

Что изучаем

Различать чат и агентную среду; запускать OpenCode из правильной папки; применять AGENTS.md, plan и permissions.

Что делаем

Журнал настоящего чтения файла, план из 3–5 шагов, AGENTS.md и доказательство ограничения записи; ручной отчёт.

Подготовка и независимый старт

Из корня полного комплекта: python scripts/start_lesson.py 02 ../my-lesson-02. Перейдите в созданную папку. Либо скачайте отдельный starter с портала и распакуйте его. Не копируйте конфиги поверх своей прошлой работы. Исходные файлы · Материалы.

Объяснение

У чата нет автоматического доступа к папке. Агентная среда даёт модели инструменты и возвращает их результаты в контекст. AGENTS.md описывает правила работы, но сам не блокирует запись. permission.edit=deny запрещает изменение через инструменты среды. Это не изоляция всей ОС: работаем только в отдельной учебной папке.

Шаги

  1. Запустите python --version и opencode --version. При отсутствии OpenCode используйте инструкцию free-stack.md; на настройку максимум 15 минут.
  2. Откройте терминал в starter, выполните git init, git add . и git commit -m "lesson start". При запросе автора задайте локальное учебное имя и адрес, не меняя глобальные настройки.
  3. Запустите opencode, выберите доступную бесплатную модель через /models. Убедитесь, что не подключён платный провайдер.
  4. Переключитесь в plan клавишей Tab, попросите прочитать REQUIREMENTS.md и предложить план проверки без изменения файлов.
  5. Переключитесь в course. Попросите изменить restricted.txt. Сохраните событие отказа инструмента или честно отметьте, что модель не пыталась его вызвать.
  6. Запустите python check_integrity.py. Скопируйте отчёт в reports/02.md вручную, выполните git diff. Объясните, какие правила были текстовыми, а какие техническими.

Что должно получиться

Журнал настоящего чтения файла, план из 3–5 шагов, AGENTS.md и доказательство ограничения записи; ручной отчёт.

Проверка и критерии сдачи

  • В read виден REQUIREMENTS.md, а не пересказ из пользовательского запроса.
  • check_integrity.py проходит: защищённый файл не изменён.
  • У edit и bash стоит deny; отсутствие попытки edit помечено как непроверенный runtime-запрет.
  • Отчёт содержит версию OpenCode, модель и способ запуска.

Что показать преподавателю

Чем AGENTS.md отличается от opencode.json? Почему запрет edit при разрешённом bash не гарантирует запрет записи? Покажите рабочую папку текущей сессии. Сдайте отчёт, исходные доказательства и свою рабочую папку. Самоотметка на сайте не является оценкой.

Для сильных

В отдельной копии разрешите запись только reports/* и проверьте сохранение отчёта. Покажите один разрешённый и один отклонённый вызов.

Если модель недоступна, используйте резервный маршрут. Непроведённые живые проверки отмечайте NOT_RUN.
