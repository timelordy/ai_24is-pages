Рубрика оценки

Единая шкала для каждой пары: 10 баллов. 7 пар — 70. Перевод в официальную отметку согласуется с кафедрой; эта рубрика не меняет утверждённую систему аттестации.

Критерий 0 1 2 3
Выполнение (0–3) Нет результата Частично Основной результат с ограничениями Все обязательные сценарии выполнены
Проверка (0–3) Нет доказательств Только happy path Есть ошибка и реальный вывод Независимый новый вход, честные ограничения
Индивидуальное объяснение (0–2) Не объясняет Объясняет с подсказкой Сам объясняет и прогнозирует новый вход —
Воспроизводимость (0–2) Нет исходников Комплект неполный Есть версия, запрос, файлы, команды и журнал —

Минимальная сдача пары: 6/10, не менее 1 за объяснение и 1 за проверку, выполнены обязательные безопасные границы. Подмена тестов, раскрытие реальных секретов или выдуманный журнал требуют исправления работы, а не компенсации другими баллами.

Минимум курса: сданы все семь работ, в том числе один живой read, загрузка skill, исправление с неизменными тестами, MCP tool call, reviewer task и финальные негативные сценарии. При техническом переносе live-сценария статус «ожидает проверки», не автоматический незачёт; доступ без оплаты обеспечивает преподаватель.

Расширения не обязательны: новый контрпример, дополнительный тест, второй контролируемый прогон. Они могут повысить балл в пределах критерия, но не компенсируют отсутствие индивидуального объяснения. Скорость ответа, бренд, размер модели и тариф не оцениваются.
