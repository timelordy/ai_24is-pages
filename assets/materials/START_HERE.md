# Студенту: как начать

## Что понадобится

1. Аккаунт GitVerse.
2. Ссылка-приглашение на задание GitVerse Lab.
3. Git, Node.js 20+ и VS Code на учебном ПК.
4. Плагин GigaCode для VS Code и выполненный вход.

Никаких API-ключей преподавателя, банковских карт и общих паролей. Если GigaCode Sessions недоступны вашему аккаунту, работайте через GigaCode в VS Code: критерии задания от этого не меняются.

## Обычный цикл каждой работы

```text
получить персональный форк
→ создать ветку
→ прочитать TASK.md и REQUIREMENTS.md
→ сначала дать прогноз и план
→ выполнить ограниченное изменение
→ посмотреть git diff
→ запустить npm test
→ проверить приложение вручную
→ commit и push
→ Merge Request
→ коротко объяснить результат
```

## Первые команды

```bash
git clone <адрес вашего персонального форка>
cd <папка репозитория>
npm test
npm run start
```

Откройте адрес, который покажет сервер. Не открывайте рабочие документы, домашнюю папку или чужие репозитории агенту. Для курса используются только синтетические данные.

## Что считается доказательством

- реальный diff;
- вывод тестов;
- воспроизведённый сценарий в браузере;
- ссылка на задачу, ветку и Merge Request;
- ваше объяснение, а не фраза агента «всё работает».

Каждая лабораторная независима: если пропустили предыдущую, используйте новый персональный форк следующего задания.
