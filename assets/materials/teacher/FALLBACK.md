# Если бесплатная модель недоступна

До занятия проверьте основной маршрут из учебной сети. Подготовьте один ПК с работающим OpenCode и бесплатной либо опциональной локальной моделью. Сохраните обезличенный пример журнала для разбора, явно подписанный как запись преподавателя.

1. На 15-й минуте прекратите настройку неработающего маршрута. Зафиксируйте ошибку и время, не просите оплату.
2. Проверьте другую явно бесплатную модель в OpenCode. Не добавляйте чужие токены и не меняйте регион обходными средствами.
3. Если доступен Gemini CLI, используйте его для чтения и анализа, учитывая другой формат конфигурации. Вторая сессия review — ручной резерв, а не автоматический subagent OpenCode.
4. Без доступного агента студент продолжает в привычном чате: передаёт только учебные файлы, составляет план, вручную применяет и проверяет patch. Для MCP выполняет probe_mcp.py — это настоящий локальный вызов процесса, но не выбор инструмента LLM.
5. Живые read/skill/task/permissions проверяются по очереди на подготовленном ПК либо на дополнительном занятии. В отчёте до этого NOT_RUN. Не помечайте обязательную агентную компетенцию освоенной только по просмотру видеозаписи.

На паре 1 вместо второй модели можно использовать ответ соседа или sample-response.json. Пометка «учебный образец» обязательна. За качество тарифа баллы не начисляются.

Если у всей группы нет ни одного бесплатного агентного маршрута, это NO-GO для проведения пар 2–7 в заявленном формате. Перенесите инструментальную часть или подготовьте локальный ПК; не подменяйте программу незаметно.
