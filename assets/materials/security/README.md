# Безопасность

Все заявки и регламенты вымышленные. Они не описывают реальные процедуры КГАСУ и не используются для управления зданиями.

В практикум и внешние чаты не вводите пароли, API-ключи, персональные данные, реальные обращения и рабочие документы. Отчёту достаточно учебного идентификатора без ФИО.

Практикум не обращается к LLM и не запускает команды. Скопированный запрос студент отправляет в выбранный чат сам. Ответ модели отображается как текст, не исполняется как HTML или код. Строка «игнорируй правила» внутри заявки остаётся данными.

Программа не обещает общего решения prompt injection. В этом курсе нет подключённых привилегированных инструментов. Показательный безопасный пример не доказывает защищённость произвольного агента.

Данные отчёта могут храниться только в браузере; на общем ПК скачайте свой файл и очистите свою работу кнопкой сброса с подтверждением. Никакой автоматической отправки преподавателю нет. Клиентский код и учебные эталоны можно посмотреть: официальная проверка проводится по новым карточкам преподавателя.
