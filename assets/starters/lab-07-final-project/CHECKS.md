# Базовые проверки

```bash
npm test
npm run start
```

После запуска откройте адрес из терминала и убедитесь:

1. Видны шесть заявок.
2. Статусы отображаются по-русски.
3. Заголовок, описание и приоритет не перепутаны.
4. В консоли браузера нет ошибок.

Конкретные критерии новой функции находятся в `TASK.md` каждой лабораторной.
