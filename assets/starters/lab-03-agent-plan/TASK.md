# 03. Агент исследует репозиторий и составляет план

**Цель:** Отделить чтение и планирование от выполнения и проверить, на чём основан план.

**Рабочая ветка:** `lab/03-agent-plan`

## Задание

1. Создайте ветку и зафиксируйте чистое состояние.
2. При доступе к GitVerse Sessions выберите агента **Plan**. Иначе используйте агент GigaCode в VS Code и явно запретите изменение файлов.
3. Попросите прочитать `TASK.md`, `REQUIREMENTS.md`, `CHECKS.md`, `src/app.js` и `src/tickets.js`.
4. Требуйте от агента указывать путь к файлу для каждого существенного утверждения.
5. Получите план реализации фильтра: цель, затрагиваемые файлы, неизменяемые части, проверки и команды.
6. Найдите одно слабое место плана и уточните его.
7. Выполните `git status --short` и `git diff --exit-code`.
8. Сохраните план и доказательство отсутствия изменений в `REPORT.md`.

## Рекомендуемый запрос

```text
Исследуй проект и подготовь план фильтра по статусу.
Сначала прочитай TASK.md, REQUIREMENTS.md, CHECKS.md, src/app.js и src/tickets.js.
Подтверждай выводы путями к файлам. Не изменяй файлы.
В плане укажи цель, изменяемые файлы, что не меняется, проверки и команды.
```

## Минимум

- агент реально работал с файлами проекта;
- план содержит проверки;
- студент внёс одно осмысленное уточнение;
- diff пуст.
