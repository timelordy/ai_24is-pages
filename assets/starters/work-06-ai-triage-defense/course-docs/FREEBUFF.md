# Freebuff CLI: другой помощник для Campus ServiceDesk

Freebuff CLI работает в терминале VS Code с той же папкой Campus ServiceDesk. В курсе сохраняются VS Code, Git, GitVerse, Node.js, задания и критерии оценки. Устанавливать OpenCode для этого варианта не нужно.

В основном варианте OpenCode выступает агентом, Inception предоставляет доступ к модели, а ответы составляет Mercury 3. В варианте Freebuff официальный продукт даёт доступ к агенту и его моделям. Freebuff не добавляют в `opencode.json` и не настраивают командами `/connect` или `/models` OpenCode.

## 1. Подготовь программы и папку

В работе 01 выбери «Альтернатива: Freebuff» над шагами. Пройди общие шаги 1–4: GitVerse, Git, VS Code и Node.js LTS не ниже 22.13.0. На шаге 5 установи выбранного агента. Затем выполни шаги 6–7: подготовь папку и клонируй Campus-ServiceDesk с GitVerse. Если клонирование недоступно, возьми стартовый ZIP в разделе «Файлы проекта» и распакуй его в новую папку, не поверх своей работы.

В VS Code выбери «Файл → Открыть папку» и открой сам проект. Слева должны быть `package.json`, `server.mjs` и папка `src`. Папка «Методы ИИ» служит только контейнером для проекта.

В VS Code открой «Терминал → Создать терминал». Панель команд появится внизу окна. Вводи по одной строке и нажимай Enter:

```powershell
node --version
npm.cmd --version
Get-Location
Get-ChildItem
```

Проверь вывод: в первых двух строках есть версии, путь ведёт к Campus-ServiceDesk, а в списке есть `package.json`. Если команда не найдена, после установки Node.js перезапусти VS Code. Если открыт не тот проект, открой нужную папку и создай новый терминал.

## 2. Установи и запусти Freebuff

В обычной строке терминала VS Code выполни:

```powershell
npm.cmd install -g freebuff
freebuff.cmd
```

Дождись, пока команда установки завершится без ошибки. Затем запусти Freebuff из папки проекта. Суффикс `.cmd` нужен в Windows, если PowerShell блокирует `npm.ps1`. В других оболочках используй официальные команды `npm install -g freebuff` и `freebuff`.

Если `freebuff.cmd` не найден, закрой и открой VS Code, снова открой папку проекта и повтори запуск. Если установка запрещена правилами учебного компьютера или завершается ошибкой, покажи текст преподавателю. Не меняй системные ограничения ради занятия.

После запуска в терминале появится Freebuff или приглашение войти. Сообщения вводи в поле агента. Для обычных команд PowerShell открой отдельный терминал.

## 3. Войди в свой аккаунт

Следуй входу, который показывает официальный CLI. Если он предлагает ссылку, открой её в браузере, войди в свой личный аккаунт и вернись в терминал. Если программа просит повторить запуск, снова выполни `freebuff.cmd` из папки проекта.

Для обычного маршрута Freebuff не нужен ключ Inception или отдельный API-ключ модели. Платёжная карта и платная подписка ради занятия не требуются. Регистрация, доступные модели, лимиты и доступность сервиса могут меняться.

Один человек использует свой аккаунт. Сервис может запросить проверку личности, документ и селфи, а также телефон. Преподавателю эти данные передавать не нужно. Если проверка недоступна или ты не хочешь её проходить, выбери OpenCode или готовый пример преподавателя без снижения оценки. Не используй чужую личность, общий аккаунт, дополнительные аккаунты ради лимита или обход региональных ограничений.

Проверь, что CLI принимает сообщение. Это ещё не доказывает, что агент читает файлы проекта.

## 4. Проверь первый ответ по настоящим файлам

Отправь в поле Freebuff:

```text
Не меняй файлы, настройки и историю Git. Не устанавливай зависимости.
Покажи путь открытого проекта. Прочитай package.json и найди источник 12 учебных заявок Campus ServiceDesk.
Назови файл и количество записей. Покажи заявку №101, её заголовок и аудиторию.
Если файл недоступен, остановись и сообщи об этом. Не ищи обход ограничения.
```

Это просьба работать без правок, а не техническая блокировка записи. Просматривай действия, пути и команды; не разрешай изменения приложения. Открой названный файл в VS Code сам. В исходном проекте данные находятся в `src/data.js`: сверь 12 записей и заявку №101 о проекторе в аудитории 305. Если версия отличается, покажи расхождение преподавателю, не подгоняй файлы под ответ агента.

Результат: объяснение опирается на файлы именно твоего проекта, и ты сам проверил хотя бы одну запись. Общий ответ без прочитанного файла не считается проверкой.

## 5. Запусти сайт и покажи результат

На шаге 9 создай рабочую ветку по инструкции выбранного агента. Приложение в работе 01 не меняем. На шаге 10 можно попросить агента прочитать `package.json` и предложить готовую команду запуска без правок и новых зависимостей. Сначала проверь команду. Можно запустить самому в отдельном терминале VS Code:

```powershell
npm.cmd start
```

Терминал оставь открытым. Открой в браузере адрес из вывода сервера. Если порт занят, не останавливай чужие процессы: попроси преподавателя помочь выбрать свободный порт. Если страница не открывается, проверь, что сервер ещё работает, и покажи точную ошибку.

Найди «Всего заявок: 12», заявку №101 и ещё одну заявку. Сопоставь страницу, файл и ответ агента. В отдельном терминале выполни:

```powershell
git diff
git status --short
```

Проверь список изменений. Код приложения должен остаться прежним; собственные заметки и согласованные файлы подготовки могут отличаться. После скачивания ZIP история Git может отсутствовать. Перед первым коммитом проверь, какие файлы в него войдут. Если не уверен, спроси преподавателя. Не выбирай команды наугад.

На шагах 11–13 при необходимости уточни ответ и сохрани короткую заметку. Покажи преподавателю сайт, файл с заявками и свою проверку. Отмечай шаг после выполнения. Для Freebuff не нужно устанавливать OpenCode или входить в Inception.

## 6. Как работать в заданиях 02–06

Сначала попроси план без правок: «Прочитай задание и предложи план. Пока не меняй файлы и не выполняй команды записи». Уточни допустимые файлы и разреши только согласованные изменения. Названия Plan и Build в карточках основного маршрута относятся к OpenCode; не ищи такие же режимы в Freebuff.

После изменений открой Source Control («Управление версиями») в VS Code, проверь `git diff` и выполни `npm.cmd test`. Затем проверь сайт сам. Коммит сохраняет выбранные файлы в истории на компьютере, а push отправляет их на GitVerse. Начиная со второй работы, отправляй результат только в свой форк и свою ветку. Покажи преподавателю, какие изменения сделал ты.

| Работа | Что проверяем независимо от агента |
| --- | --- |
| 02 | Свой форк и ветка, поиск: `305` находит №101, пустой запрос возвращает список, запрос без совпадений показывает пустой результат. Просмотр diff, коммит и push в свой форк. |
| 03 | Только разрешённая преподавателем основа, сохранённый свой поиск, форма и REST API, тесты и происхождение изменений. |
| 04 | Заявка сохраняется после остановки и запуска сервера с тем же файлом SQLite. |
| 05 | Полностью необязательное дополнение. Просьба о review без правок не гарантирует запрет записи; проверяй действия и diff. |
| 06 | `demo`, `invalid` и `error` работают как учебные режимы. Они не подключаются к живой модели. Freebuff может помочь написать код, но сам не служит AI-endpoint приложения. Проверь ручное создание заявки после ошибки и покажи свой пример. |

Закрытые H3/H4 foundation/final выдаёт только преподаватель. Не скачивай их по догадке и не обходи отказ чтения. Работай только с явно разрешённым комплектом по заданию; `_teacher-reference` остаётся вне коммита. Не расширяй доступ агента к закрытым материалам ради сравнения.

## 7. Безопасность и восстановление

Используй официальный Freebuff CLI в сеансе под своим управлением. Не подключай его бесплатный доступ через скрипты, обёртки, чужие клиенты или прямые inference endpoints.

`opencode.json` сохраняй: он понадобится для OpenCode. Его `external_directory=deny` и запреты `.env` **не ограничивают Freebuff**. Работай только в своей учебной копии, проверяй запросы к файлам и команды. Не передавай агенту `.env`, API-ключи, пароли, личные данные, закрытые файлы преподавателя. Они также не должны попадать в коммиты, снимки экрана и отчёты.

Если доступ недоступен, вход или проверка не проходят, закончился лимит либо нет сети, прекрати повторные попытки. Обсуди с преподавателем другой вариант: OpenCode Free, NVIDIA после проверки доступа или готовый офлайн-пример. Для этого задания не нужно покупать подписку или обходить ограничения. Оценка зависит от проверки и объяснения результата.

Чтобы сменить агента, сохрани файлы и заметки, заверши его сеанс и открой другого в той же папке. Не клонируй проект заново, не удаляй `.git` и `opencode.json`. В курсе выбери другой вариант и выполни его установку и вход. Отметки шагов описывают уже проверенные учебные результаты, а не установленные программы; переключение не выполняет настройку автоматически.
