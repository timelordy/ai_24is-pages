# Если Python пока незнаком

На диагностику отведено 10–15 минут. В проекте не нужны классы, асинхронность и фреймворки.

```python
rows = [{"id": 3, "status": "done"}, {"id": 4, "status": "todo"}]

def done_ids(rows):
    result = []
    for row in rows:
        if row["status"] == "done":
            result.append(row["id"])
    return result

assert done_ids(rows) == [3]
```

`rows` — список; каждый элемент — словарь. `row["status"]` читает поле. Функция возвращает новый список id. `assert` сравнивает наблюдаемый результат с ожидаемым и завершает программу ошибкой при расхождении.

Сначала предскажите ответ на двух задачах todo. Затем измените вход и запустите. Не меняйте assert только потому, что он падает: сначала разберитесь с требованием.
