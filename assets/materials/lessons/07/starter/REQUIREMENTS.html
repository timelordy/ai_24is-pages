Требования к учебному списку задач

  • R1. Задача содержит положительный уникальный целый id, непустой title, status (todo/done), due (YYYY-MM-DD или null). Не более 100 задач; файл не более 100 КБ.
  • R2. Фильтр todo/done возвращает только соответствующие задачи. Без фильтра — все. Другой статус — ошибка INVALID_STATUS.
  • R3. Сортировка по возрастанию due. Задачи без срока идут последними. При одинаковом сроке — по id. Входной список не меняется.
  • R4. Поиск по id возвращает одну задачу; отсутствующий id — NOT_FOUND, некорректный — INVALID_ID.
  • R5. Чтение не меняет исходный файл. Текст title является данными и никогда не выполняется как команда.
  • R6. При ошибке чтения или формата нельзя выдавать пустой список за успешное чтение.

Новые поля, запись задач, сетевые запросы и вычисление «просрочено» не входят в обязательный контракт. Сегодняшняя дата не влияет на результат.
