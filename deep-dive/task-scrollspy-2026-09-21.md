# Scrollspy навигации задания

## Обзор

Боковое меню страницы задания теперь отражает видимый смысловой раздел. Состояние вычисляется по положению целевых секций относительно закреплённой шапки, поэтому оно меняется и при ручной прокрутке, и после перехода по hash-ссылке. Обычная прокрутка не меняет URL и не засоряет историю браузера.

## Ключевые компоненты

- `assets/task-page.js`: ссылки меню получили `data-toc-target`, а `bindTaskToc()` связывает их с секциями страницы.
- `assets/task-page.js`: обновление геометрии ограничено одним вызовом на кадр через `requestAnimationFrame`.
- `assets/task-page.js`: активная ссылка получает класс `active` и `aria-current="location"`; обработчики снимаются перед повторным рендером.
- `assets/style.css`: активный пункт выделен цветом и материалом; длинное меню ограничено высотой окна, мобильная версия сохраняет горизонтальную прокрутку.
- `assets/app.js` и `index.html`: версии ресурсов изменены, чтобы браузер не использовал старый JavaScript и CSS из кеша.

## Основные концепции

### Состояние из геометрии

Текущий раздел определяется как последняя секция, верх которой пересёк линию под шапкой. Это надёжнее проверки `location.hash`: hash показывает последний переход, но не положение после ручной прокрутки.

### Ограничение работы на кадр

Событие `scroll` может срабатывать много раз между отрисовками. `requestAnimationFrame` объединяет вызовы и оставляет одно чтение геометрии на кадр, что уменьшает лишнюю нагрузку.

### Жизненный цикл обработчиков

Страница перерисовывает содержимое при смене hash. Функция очистки удаляет старые глобальные обработчики перед новой привязкой, чтобы один скролл не запускал несколько копий логики.

### Доступность

`aria-current="location"` сообщает вспомогательным технологиям, какой пункт соответствует текущему месту на странице. В каждый момент атрибут есть только у одной ссылки.

### Адаптивная навигация

На узком экране меню становится горизонтальным. При смене раздела оно прокручивается ровно настолько, чтобы активная ссылка попала в видимую область. При `prefers-reduced-motion` используется мгновенное перемещение.

## Ограничения и альтернативы

Логика предполагает, что ссылки меню и секции идут в одном порядке. Если структура задания изменится, порядок `data-toc-target` нужно сохранить. `IntersectionObserver` уменьшил бы число обработчиков прокрутки, но при высоких раскрытых блоках дал бы неоднозначный выбор между несколькими пересекающимися секциями; расчёт относительно одной линии проще для этой страницы.
