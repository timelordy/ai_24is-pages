# 01. GitVerse, VS Code и первый проверенный ответ GigaCode

**Цель:** Настроить реальную среду, получить персональный форк и проверить объяснение существующего кода.

**Рабочая ветка:** `lab/01-environment`

## Задание

1. Примите приглашение GitVerse Lab и откройте свой персональный форк.
2. Клонируйте репозиторий в отдельную учебную папку.
3. Откройте проект в VS Code, установите GigaCode и выполните вход.
4. Запустите `npm test`, затем `npm run start`.
5. Попросите GigaCode объяснить `src/tickets.js`: назначение функций, входы и результаты.
6. Выберите три утверждения AI и подтвердите каждое конкретной строкой или функцией исходника.
7. Найдите хотя бы одну неточность, чрезмерную уверенность или пропущенную оговорку. Если ответ полностью корректен, сформулируйте риск и новый проверочный вопрос.
8. Заполните `REPORT.md`, сделайте commit и push.

## Минимум

- проект запускается;
- тесты проходят;
- сохранён исходный ответ GigaCode;
- проверены три утверждения;
- есть собственный вывод студента.
