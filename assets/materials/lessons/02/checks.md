# Проверочные сценарии

- В read виден REQUIREMENTS.md, а не пересказ из пользовательского запроса.
- check_integrity.py проходит: защищённый файл не изменён.
- У edit и bash стоит deny; отсутствие попытки edit помечено как непроверенный runtime-запрет.
- Отчёт содержит версию OpenCode, модель и способ запуска.

1. Начните с неизменённого starter, зафиксируйте исходный результат.
2. После работы запустите `python -m unittest -v` и `python check_integrity.py`.
3. Сверьте исходные доказательства с отчётом. Скриншот текста ответа не заменяет журнал инструмента.
4. Повторите один новый вход, выбранный преподавателем. PASS/FAIL/NOT_RUN указываются отдельно.
