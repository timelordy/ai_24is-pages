---
name: acceptance-check
description: Проверить задачу Campus ServiceDesk перед Merge Request.
---

1. Прочитай `TASK.md` и выпиши каждый пункт Definition of Done.
2. Для каждого пункта укажи доказательство: тест, HTTP-сценарий, UI-сценарий или diff.
3. Запусти `npm test`; не пересказывай ожидаемый результат вместо реального вывода.
4. Проверь `git diff` на несвязанные изменения и новые dependencies.
5. Перечисли непроверенные риски.
6. Во время этой проверки не изменяй код автоматически.
