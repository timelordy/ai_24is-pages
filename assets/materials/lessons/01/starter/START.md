# Пара 1 — начните с LAB.md

Сегодня OpenCode и Git не нужны. Нужны эта папка, любой доступный чат с LLM и Python 3.11+. Полный сценарий на 90 минут находится в `LAB.md`.

1. Откройте `notes.txt`. Отправьте модели запрос: «Выдели учебные задачи из заметок. Для каждой укажи название, статус и срок». Сам файл пока не прикладывайте. Сохраните запрос и ответ.
2. Отправьте второй запрос вместе с текстом `notes.txt`: попросите JSON с полями `title`, `status`, `due`; если точной даты нет — `due=null`; ничего не придумывать. Сохраните запрос и ответ.
3. Сверьте каждое поле второго ответа с `notes.txt`. Запишите хотя бы одну найденную ошибку или спорное место.
4. Выполните `python diagnosis.py`. Исправьте функцию `done_ids`, чтобы программа напечатала `Python diagnosis passed`.

Четыре пункта ниже — быстрая ориентация. Сдача требует полного benchmark из `LAB.md`, а не одного ответа.

Никаких личных данных и платных ключей. Полное задание находится на портале.
