Проверка лабораторной 1

  1. В runs/baseline.json и runs/improved.json по восемь уникальных case B01–B08.
  2. Оба файла являются JSON-массивами; сырые ответы не исправлялись после запуска scorer.
  3. python score_benchmark.py runs/baseline.json и improved-команда завершаются без ошибки и показывают 24 проверяемых поля.
  4. Между прогонами совпадают модель, исходные заметки и порядок; меняется только формулировка запроса.
  5. В отчёте есть две метрики, два разобранных риска и ограничение эксперимента.
  6. python diagnosis.py печатает Python diagnosis passed.
  7. На новом кейсе студент сначала записывает прогноз, затем выполняет запрос и сверяет результат.

Преподаватель выборочно сверяет один due=null, одну точную дату и один статус. Переписанный вручную «идеальный» JSON не принимается без сохранённого сырого ответа.
