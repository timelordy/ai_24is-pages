# ServiceDesk Lite

## Команды

- запуск: `npm run start`
- все тесты: `npm test`

## Границы

- Сначала прочитай `TASK.md`, `REQUIREMENTS.md` и `CHECKS.md`.
- Перед изменением дай план из 3–6 шагов.
- Не добавляй зависимости и не меняй формат данных.
- Не переписывай проект на фреймворк.
- Меняй минимальное число файлов, прямо связанных с задачей.
- Не меняй тест ради маскировки ошибки в коде.
- После изменения запусти тесты и покажи реальный результат.
- Сообщи, что проверено вручную и что осталось непроверенным.
- Если требование неоднозначно, задай вопрос до правки.

## Git

- одна задача — одна feature-ветка;
- commit: `labNN: краткое описание`;
- в Merge Request перечисли проверки и риски.
