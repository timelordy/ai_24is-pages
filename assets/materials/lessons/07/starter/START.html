Сначала откройте LAB.md: требуется семь независимых прогонов, классификация отказов и живой новый вход.

Это независимое состояние: предыдущая пара не нужна. Работайте в копии этой папки. Полное задание находится на портале или в lessons/07/README.md учебного репозитория.

  1. python --version — нужен Python 3.11+.
  2. python -m unittest -v — ожидаются 5 успешных тестов.
  3. opencode — запускать именно в этой папке; модель выбирается через /models.
  4. Результаты храните в reports/07.md. Для baseline-профиля запись отчёта выполняет студент вручную.

Никаких личных данных или платных ключей. Подробнее: START_HERE.md и free-stack.md в полном комплекте.
