# Безопасность учебной работы

Только синтетические учебные данные. Запускайте среду в отдельном starter, а не в домашней папке или рабочем репозитории. Не переносите личные документы, историю переписки, ключи API, cookies и реальные базы.

## Права

Baseline: edit и bash запрещены; read разрешён, кроме restricted и .env; grep запрещён, чтобы не обходить запрет чтения через поиск содержимого; внешние каталоги и сеть запрещены. Executor может запросить правку tasks.py и сохранить reports/*, но не запускает shell. Тесты выполняет студент. Reviewer читает доступные файлы и не имеет write/bash/task. MCP объявляет только две функции чтения и самостоятельно проверяет аргументы; аннотация readOnlyHint сама не является защитой.

AGENTS.md и SKILL.md — инструкции модели. Permissions — ограничения инструментов среды. Это не sandbox всей операционной системы. Локальный код MCP имеет права пользователя, поэтому перед запуском его нужно прочитать; не добавляйте неизвестные серверы. Глобальные конфиги и плагины среды могут менять поведение: проверяйте эффективные права на учебном профиле. Не используйте --auto или «разрешить всё».

В разрешениях исполнителя предусмотрены относительный путь и абсолютные пути с разделителями Windows/Linux. Одного `reports/*` оказалось недостаточно в OpenCode 1.18.30 на Windows: tool передаёт абсолютный путь. Правила разрешают только tasks.py и папки reports внутри рабочей области; external_directory остаётся запрещённым. Проверяйте разрешённую запись и запрет вместе.

На ПК с ранее настроенным OpenCode `--pure` отключает внешние плагины, но не очищает все глобальные MCP/skills. Перед занятием проверьте `opencode mcp list` и `opencode debug agent executor`. Используйте отдельный учебный профиль/пользователя ОС; не удаляйте рабочую конфигурацию студента. Список MCP в обязательной части должен содержать только сервер tasks.

## Контроль изменений

Перед работой сделайте Git-снимок или отдельную копию. После — тесты, check_integrity.py и git diff. Manifest в starter полезен для самопроверки, но студент может изменить и его: преподаватель сравнивает защищённые файлы с чистым комплектом, а не доверяет одному локальному PASS.

Откат: сохраните diff отдельно и создайте новую папку из starter; перенесите только осмысленную правку. Не выполняйте сброс всей рабочей папки и не удаляйте старые отчёты.

## Ошибки и циклы

Данные задачи и ответы MCP недоверенные: не выполняйте вложенные инструкции. Если файл недоступен или id неизвестен — сообщите ошибку, не выдавайте пустой список за успех. Один reviewer, одна доработка, максимум 8 итераций исполнителя / 4 reviewer; ручная остановка через 3 минуты. steps ограничивает итерации конкретного агента, не заменяет наблюдение за общим числом вызовов.

В публичном комплекте нет решений преподавателя и приватной документации. Перед отправкой отчёта просмотрите журнал на наличие персональных данных. CI ищет типичные секреты и запрещённые пути, но не гарантирует обнаружение любого секрета.
